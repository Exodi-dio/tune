# Tune

Standalone local Android music player. Reworked by **exodi_dio**.

- Plays music directly from local files — no PC, no account, no sync.
- All audio formats via FFmpeg + AAudio, full metadata, synced lyrics in all languages.
- Bitchord-style artist screen with transitions.
