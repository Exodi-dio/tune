# Contributing to Tune

Thanks for stopping by. Tune is a small project, so the process is small too.

## Bugs and ideas

Open an [issue](https://github.com/Exodi-dio/tune/issues) — bug reports
with a screenshot get fixed fastest. One idea per feature request, please.

## Code

- All code lands through GitHub: fork, branch, pull request.
- Everything builds and verifies in GitHub Actions — CI must be green.
- Match the existing Kotlin + Jetpack Compose style; keep it offline-first.
- The project is GPL-3.0: contributions land under the same license.

## Questions

Use [Discussions](https://github.com/Exodi-dio/tune/discussions) for
anything that isn't a bug or a feature — setup help, device quirks,
roadmap talk.
