# Tune Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (cloud-only: every build/test/run happens in GitHub Actions; coordinate with `gh`; never execute gradle/adb/emulator locally). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework tune's Android app into Tune, a standalone local music player, and ship an installable debug APK from a GitHub Release — with zero local builds.

**Architecture:** Repo root = tune `mobile/` subtree. Bulk file ops run on GitHub runners via dispatch workflows; targeted/new files land via the Contents API; every phase verified by a green Actions run.

**Tech Stack:** Kotlin Multiplatform (androidApp + sharedLogic), FFmpeg 8.1 + AAudio (JNI), Room, Jetpack Compose + Haze, Gradle 9.5.0 / AGP 9.3.1 / JDK 21.

**Spec:** docs/superpowers/specs/2026-09-24-tune-design.md

## Global Constraints

- Package `com.exodidio.tune` (dev flavor `com.exodidio.tune.dev`); display name Tune; versionName 0.1.0.
- minSdk 31, compileSdk/targetSdk 36, AGP 9.3.1, Kotlin 2.4.10, NDK 30.0.15729638, CMake 3.22.1, JDK 21.
- GPLv3; attributions in NOTICE; About screen says "Reworked by exodi_dio".
- Cloud-only: no local builds/tests/runs ever. Files over ~500KB move via Trees API or runner jobs, never giant `-f` args.
- Branding gate: CI fails on case-insensitive `tune|exodidio` outside NOTICE.
- Perf: low-spec mode (`isLowRamDevice()` or Reduce-animations) disables Haze/parallax/particles/palette animation; lazy lists with keys; list thumbnails max 256px; R8 + Baseline Profiles.

## Review Focus

- Weak-chip jank on scroll and screen transitions — expect gates to hold and the owner device test to confirm.
- Audio-permission denied — expect a calm empty-state screen, never a crash.
- Corrupt or unsupported file during scan — expect skip-and-count, scan always completes.
- Missing tags — expect "Unknown artist/album" fallbacks everywhere, never blank rows.
- Artist screen back/rotate — expect no crash and retained position.

- [ ] **Step 1: Create import.yml via API**

```yaml
name: import-base
on:
  workflow_dispatch:
permissions:
  contents: write
jobs:
  import:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          path: tune
      - uses: actions/checkout@v4
        with:
          repository: exodidio/tune
          ref: master
          sparse-checkout: |
            mobile
            scripts/build-ffmpeg-android.sh
          path: up
      - name: Transplant mobile subtree to repo root
        run: |
          set -eux
          rm -rf tune/androidApp tune/sharedLogic tune/gradle tune/gradlew tune/gradlew.bat tune/settings.gradle.kts tune/build.gradle.kts tune/gradle.properties tune/iosApp tune/tools
          cp -a up/mobile/androidApp up/mobile/sharedLogic up/mobile/gradle up/mobile/gradlew up/mobile/gradlew.bat up/mobile/settings.gradle.kts up/mobile/build.gradle.kts up/mobile/gradle.properties up/mobile/tools tune/
          mkdir -p tune/scripts
          cp -a up/scripts/build-ffmpeg-android.sh tune/scripts/
          chmod +x tune/gradlew
      - name: Commit and push
        run: |
          cd tune
          git config user.name "tune-bot"
          git config user.email "tune-bot@users.noreply.github.com"
          git add -A
          git commit -m "Import tune mobile base (GPLv3, see NOTICE)" || echo "nothing to commit"
          git push origin HEAD:main
```

**Files:**

- [ ] **Step 1: Create ci.yml via API**

```yaml
name: ci
on:
  push:
    branches: [main]
  pull_request:
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: "21"
      - uses: android-actions/setup-android@v3
      - name: Install SDK packages
        run: |
          sdkmanager "platform-tools" "platforms;android-36" "build-tools;36.0.0" "ndk;30.0.15729638" "cmake;3.22.1"
      - uses: gradle/actions/setup-gradle@v4
      - name: Restore FFmpeg build cache
        uses: actions/cache@v4
        with:
          path: build/ffmpeg
          key: ffmpeg-arm64-v8a-v1
      - name: Build FFmpeg arm64-v8a
        run: bash scripts/build-ffmpeg-android.sh arm64-v8a
      - name: Unit tests
        run: ./gradlew :sharedLogic:testAndroidHostTest --no-daemon
      - name: Assemble debug
        run: ./gradlew :androidApp:assembleDevDebug --no-daemon
      - name: Branding gate
        run: |
          if grep -rniE 'tune|exodidio' --exclude-dir=.git --exclude=NOTICE . ; then echo "STALE BRANDING"; exit 1; fi
      - uses: actions/upload-artifact@v4
        with:
          name: tune-debug-apk
          path: androidApp/build/outputs/apk/dev/debug/*.apk
```

### Phase 8: Release v0.1.0-test

**Files:**
- Create: `.github/workflows/release.yml`

```yaml
name: release
on:
  push:
    tags: ["v*"]
  workflow_dispatch:
jobs:
  release:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with: {distribution: temurin, java-version: "21"}
      - uses: android-actions/setup-android@v3
      - name: Install SDK packages
        run: sdkmanager "platform-tools" "platforms;android-36" "build-tools;36.0.0" "ndk;30.0.15729638" "cmake;3.22.1"
      - uses: gradle/actions/setup-gradle@v4
      - uses: actions/cache@v4
        with: {path: build/ffmpeg, key: ffmpeg-arm64-v8a-v1}
      - run: bash scripts/build-ffmpeg-android.sh arm64-v8a
      - run: ./gradlew :androidApp:assembleDevDebug --no-daemon
      - name: Verify APK identity
        run: |
          APK=$(ls androidApp/build/outputs/apk/dev/debug/*.apk | head -1)
          aapt dump badging "$APK" | grep -E "package:|application-label:"
          aapt dump badging "$APK" | grep -q "package: name='com.exodidio.tune'" || exit 1
          aapt dump badging "$APK" | grep -q "application-label:'Tune'" || exit 1
          cp "$APK" "tune-${GITHUB_REF_NAME}.apk"
      - uses: softprops/action-gh-release@v2
        with:
          files: tune-*.apk
          prerelease: true
```
